# التحليل الاستراتيجي الشامل

# الإدارة الاستراتيجية

## تحليل SWOT

**تحليل SWOT:**

هو أسلوب تحليلي لمعرفة: نقاط الضعف ونقاط القوة في المؤسسة (ويمكن استخدامه لتحليل مقومات شخص أو مجموعة) ومعرفة الفرص والتهديدات التي تواجه المؤسسة.

### مصفوفة التحليل الرباعي (تحليل SWOT)

| نقاط القوة Strengths | نقاط الضعف Weaknesses |
| :--- | :--- |
| أية إمكانيات داخلية ذاتية موجودة فعلاً تساعد على استغلال الفرص المتاحة والممكنة وعلى مكافحة التهديدات يمكن التطرق للأسئلة التالية:<br>أ- ماهي نقاط القوة؟<br>ب- ماهي المميزات الإيجابية (مواهب، مهارات، تصرفات، أقوال)؟<br>ت- ماهي مصادر القوة؟ | أية ظروف وعوامل نقص داخلية موجودة فعلاً تعيق من القدرة على استغلال الفرص يمكن التطرق للأسئلة التالية:<br>أ- ماهي نقاط الضعف؟<br>ب- ماهي الأمور المزعجة أو المخلة بالاتزان؟<br>ت- ماهي الأمور التي تحتاج إلى معالجة، متابعة، دعم وتقوية؟ |
| **الفرص Opportunities** | **التهديدات (التحديات) Threats** |
| أية ظروف أو اتجاهات خارجية ذات أثر إيجابي تمكن أو مكنت فرصة للتطور والنمو يمكن التطرق للأسئلة التالية:<br>أ- ماهي التغيرات أو الظروف الخارجية التي ساعدت؟<br>ب- ماهي الأمور التي تم استغلالها أو يمكن استغلالها للتقدم والنمو؟<br>ت- ماهي الأمور التي ساهمت في عملية التطوير والتقدم؟ | أية ظروف أو اتجاهات خارجية قد تؤثر سلباً أو أثرت بشكل سلبي وهي عامل مهدد أو قد تسبب خسارة وضرر يمكن التطرق للأسئلة التالية:<br>أ- ماهي التهديدات والمخاطر المحيطة؟<br>ب- ماهي التغيرات التي أثرت أو قد تؤثر بشكل سلبي؟<br>ت- كيف تم التعامل مع هذه التهديدات؟ |

## مفهوم وحدة الأعمال الاستراتيجية (STRATEGIC BUSINESS UNIT (SBU))

**مفهوم وحدة الأعمال الاستراتيجية:**

هي قطاع أعمال أو خط إنتاج أو أي مركز ربحية داخل المنظمة يقوم بإنتاج وتسويق مجموعة محددة من المنتجات المترابطة وخدمة مجموعة معينة من العملاء والتعامل مع عدد معين من المنافسين.

هي وحدة من وحدات المنظمة التي يمكن تحديد رسالة وأهداف مستقلة لها والتخطيط لها بشكل مستقل عن وحدات الأعمال الأخرى. تمثل أصغر وحدة داخل المنظمة يمكن إجراء تخطيط استراتيجي لها.

## نموذج مجموعة بوسطن الاستشارية

يتم توزيع وحدات الأعمال في مصفوفة بناءً على بُعدي (معدل نمو الصناعة) و (الحصة السوقية النسبية) كالتالي:

| | حصة السوق النسبية (مرتفع 1.0) | حصة السوق النسبية (متوسط 0.50) | حصة السوق النسبية (منخفض صفر) |
| :--- | :--- | :--- | :--- |
| **معدل نمو الصناعة (مرتفع +20)** | **المجموعة الممتازة (النجوم - Stars)** | | **المجموعة الحرجة (علامة الاستفهام)** |
| **معدل نمو الصناعة (متوسط صفر)** | **المجموعة القوية (البقرة الحلوب)** | | **المجموعة الضعيفة (الكلاب - Dogs)** |
| **معدل نمو الصناعة (منخفض -20)** | | | |

**طريقة الحساب:**

يتم حساب بعدي المصفوفة كالاتي:

1.  **معدل نمو السوق أو الصناعة:**
    (إجمالي مبيعات الصناعة أو السوق خلال الفترة الزمنية ت) - (إجمالي مبيعات الصناعة أو السوق خلال الفترة الزمنية ت-1) / إجمالي مبيعات الصناعة أو السوق خلال الفترة الزمنية ت-1.

2.  **الحصة السوقية النسبية:**
    مبيعات وحدة الأعمال بالمنظمة / مبيعات أكبر منافس في السوق.

## تطبيق مصفوفة SWOT (مثال: ماكدونالدز)

| نقاط القوة | نقاط الضعف |
| :--- | :--- |
| - علامة تجارية معروفة عالمياً<br>- عمليات عالمية ومنظمة<br>- مواقع ممتازة للمحلات<br>- مكونات صنف أول<br>- علاقات قوية بالموردين | - الدوران المرتفع للكادر الوظيفي<br>- التركيز القليل على الأطعمة العضوية<br>- التنوع المحدود في المنتجات الموسمية<br>- التركيز على المنتجات التي تعتبر غير صحية |
| **الفرص** | **المخاطر** |
| - افتتاح مشاريع مشتركة أكثر<br>- الاستجابة للخيارات الأكثر صحية<br>- المبادرات التي تدعم المجتمع<br>- التوسع في أسواق جديدة | - مخاطر التلوث الغذائي مثل (E-Coli)<br>- اتجاهات نحو طرق العيش الصحية<br>- الانكماش الاقتصادي في الأسواق الرئيسية |

## مصفوفة التخطيط الاستراتيجي الكمي (QSPM)

**مصفوفة التخطيط الاستراتيجي الكمي:**

هي أداة تساعد المؤسسات على تقييم البدائل الاستراتيجية وتحديد أولوياتها بموضوعية بناءً على معايير محددة. وهي مفيدة بشكل خاص في مرحلة اتخاذ القرار حيث تسمح للمؤسسات باختيار الاستراتيجية الأكثر جاذبية بناءً على التحليل الكمي وذلك من خلال:

*   مقارنة الخيارات الاستراتيجية المتعددة بشكل موضوعي.
*   تحديد أولويات الاستراتيجيات بناءً على جاذبيتها.
*   اتخاذ قرارات مستنيرة بناءً على البيانات الكمية بدلاً من الحكم الذاتي.

# الإدارة الإستراتيجية

### فوائد QSPM

* **الموضوعية:** توفر نهجاً منظماً قائماً على البيانات لمقارنة الاستراتيجيات.
* **تحديد الأولويات:** يساعد المؤسسات على التركيز على الخيار الاستراتيجي الأكثر فائدة.
* **اتخاذ القرارات المستنيرة:** تجمع بين العوامل النوعية والكمية لدعم القرارات الشاملة.

### خطوات انشاء مصفوفة QSPM

1. **تحديد العوامل الرئيسية:** قم بإدراج العوامل الداخلية والخارجية الحرجة من مصفوفات IFE و EFE.
2. **تعيين الأوزان Assign Weights:** تعيين وزن لكل عامل بناء على أهميته بحيث يصل مجموع الأوزان إلى 1.
3. **قائمة البدائل الاستراتيجية:** تحديد الخيارات الاستراتيجية قيد الدراسة.
4. **تعيين درجات الجاذبية (Attractiveness Scores (AS:** قم بتقييم كل استراتيجية لكل عامل (1= غير جذابة، 4= جذابة للغاية).
5. **حساب إجمالي درجات الجاذبية (Total Attractiveness Scores (TAS:** اضرب الوزن في درجة الجاذبية لكل عامل وأضف قيم TAS لكل استراتيجية.
6. **تحليل النتائج:** قارن إجمالي عائد الاستثمار لكل استراتيجية، الاستراتيجية ذات أعلى عائد استثماري هي الخيار الأكثر جاذبية.

**مثال:**
فيما يلي البيانات الخاصة بشركة بيشوتكس للمنسوجات

| الرقم التسلسلي | العوامل | وزن | توسيع السوق AS | تطوير المنتجات AS |
| :--- | :--- | :--- | :--- | :--- |
| **العوامل الداخلية** | | | | |
| 1 | قوة العلامة التجارية | 0.25 | 3 | 4 |
| 2 | قدرات البحث والتطوير | 0.20 | 2 | 4 |
| 3 | الكفاءة التشغيلية | 0.30 | 3 | 3 |
| 4 | الموارد المالية | 0.25 | 4 | 3 |
| **العوامل الخارجية** | | | | |
| 1 | امكانات نمو السوق | 0.30 | 4 | 3 |
| 2 | الضغط التنافسي | 0.15 | 2 | 3 |
| 3 | اتجاهات طلب العملاء | 0.25 | 4 | 3 |
| 4 | البيئة التنظيمية | 0.30 | 3 | 2 |

### مصفوفة QSPM مع تفسير النتائج

| الرقم التسلسلي | العوامل | وزن | توسيع السوق (AS) | توسيع السوق (TAS) | تطوير المنتجات (AS) | تطوير المنتجات (TAS) |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **العوامل الداخلية** | | | | | | |
| 1 | قوة العلامة التجارية | 0.25 | 3 | 0.75 | 4 | 1.00 |
| 2 | قدرات البحث والتطوير | 0.20 | 2 | 0.40 | 4 | 0.80 |
| 3 | الكفاءة التشغيلية | 0.30 | 3 | 0.90 | 3 | 0.90 |
| 4 | الموارد المالية | 0.25 | 4 | 1.00 | 3 | 0.75 |
| | **إجمالي داخلي (TAS)** | **1.00** | | **3.05** | | **3.45** |
| **العوامل الخارجية** | | | | | | |
| 1 | امكانات نمو السوق | 0.30 | 4 | 1.20 | 3 | 0.90 |
| 2 | الضغط التنافسي | 0.15 | 2 | 0.30 | 3 | 0.45 |
| 3 | اتجاهات طلب العملاء | 0.25 | 4 | 1.00 | 3 | 0.75 |
| 4 | البيئة التنظيمية | 0.30 | 3 | 0.90 | 2 | 0.60 |
| | **إجمالي خارجي (TAS)** | **1.00** | | **3.40** | | **2.70** |

**الاستنتاج:**
في هذا المثال:
العوامل الداخلية تمنح تطوير المنتجات TAS بقيمة 3.45، بينما يحصل توسيع السوق على 3.05.
العوامل الخارجية تمنح توسيع السوق TAS بقيمة 3.40، بينما يحصل تطوير المنتج على 2.70.

**الخلاصة:**
يحقق تطوير المنتجات نتائج أعلى بناء على العوامل الداخلية بينما يحقق توسيع السوق نتائج أعلى بناء على العوامل الخارجية.
بناء على التحليل العام قد تختار الشركة تطوير المنتجات إذا كانت تعطي الأولوية للقدرات الداخلية أو توسيع السوق إذا كانت تركز على إمكانات نمو السوق الخارجية.

# مفهوم التحليل الاستراتيجي

يعرف (Scholess & Johnson, 1988) التحليل الاستراتيجي بأنه عبارة عن مجموعة من الوسائل التي تستعملها الإدارة في تحديد مدى التغير في البيئة الخارجية وتحديد الميزة التنافسية للشركة وكفاءتها في السيطرة على بيئتها الداخلية بحيث يسهم ذلك في زيادة قدرة الإدارة العليا في تحديد أهدافها ومركزها التنافسي.
